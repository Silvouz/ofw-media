# Stock branch

Videos of posts scheduled more than 8 days ahead wait here, in `stock/<due date YYYY-MM-DD>/`, so they do not count towards the GitHub Pages size limit. The `promote` workflow on `main` moves each file to `videos/` (same file name, so the URL in the Buffer queue stays valid) 9 days before its due date. Written by `scripts/publish/host_media.sh` in Silvouz/one-fact-wiser.
